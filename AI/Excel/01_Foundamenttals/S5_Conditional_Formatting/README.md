# Conditional Formatting 
هدف امروز: جدول EPC را طوری طراحی کنی که با نگاه به آن، تأخیر بحرانی، موعد نزدیک و ایراد داده را تشخیص بدهی؛ بدون رنگ‌کردن دستی.

تا امروز:

    داده را پاک‌سازی کردیم؛
    تاریخ‌ها را استاندارد کردیم؛
    ورودی‌ها را محدود کردیم.

امروز خطا و ریسک را قابل‌دیدن می‌کنیم.
```
اصل امروز: رنگ باید نتیجه‌ی یک قانون قابل‌توضیح باشد، نه جایگزین داده و شاخص.
```

 ## آماده‌سازی فایل

از فایل روز چهارم یک نسخه ذخیره کن:
```
W01_D05_EPC_Alerts.xlsx
```
برای مثال‌های امروز، چینش جدول در شیت Calendar را این‌طور در نظر می‌گیریم:
```
ستون 	عنوان 	نقش
A 	ProjectID 	کد پروژه
B 	PackageID 	کد بسته
C 	StartDate 	شروع
D 	ApprovedFinish 	موعد مصوب
E 	ActualDelivery 	تحویل واقعی
F 	Status 	وضعیت
G 	Quantity 	مقدار
H 	InputCheck 	کنترل روز چهارم
I 	SupplierID 	کد تأمین‌کننده
J 	DelayDays 	تأخیر تقویمی
K 	DueInDays 	روز باقی‌مانده تا موعد
```
ردیف اول عنوان است و داده‌ها از ردیف دوم شروع می‌شوند.

اگر ترتیب ستون‌های فایلت متفاوت است، ارجاع فرمول‌ها را متناسب تغییر بده.
یک تاریخ مبنا تعریف کن

در شیت جدید Settings:
```
سلول 	محتوا
A1 	ReportDate
B1 	=DATE(2026,4,30)
```
برای B1 نام زیر را تعریف کن:

```
ReportDate
```
امروز تاریخ گزارش را ثابت می‌گیریم تا جواب تمرین‌ها قابل‌مقایسه باشد.

برای داشبورد زنده می‌توانی بعداً مقدار آن را به این تبدیل کنی:
```
=TODAY()
```
نکته: TODAY() هنگام محاسبه‌ی مجدد فایل به‌روز می‌شود؛ ساعتِ دائماً در حال اجرا نیست.

## فرمول بولین چیست؟

فرمولی که خروجی آن TRUE یا FALSE است:

```
=J2>30
```
یعنی آیا تأخیر این ردیف بیشتر از ۳۰ روز است؟

Conditional Formatting همین منطق را استفاده می‌کند:
```
    TRUE ← قالب را اعمال کن.
    FALSE ← این قالب را اعمال نکن.
```
سه ابزار منطقی

```
=AND(J2>30,F2<>"Delivered")
```
یعنی هر دو شرط برقرار باشند.

```
=OR(F2="Pending",F2="In Progress")
```
یعنی حداقل یکی برقرار باشد.

```
=$E2=""
```
یعنی تاریخ تحویل خالی باشد.

در Conditional Formatting معمولاً نیازی نیست بنویسی:

```
=IF(J2>30,TRUE,FALSE)
```
همان مقایسه‌ی ساده کافی است:

```
=J2>30
```

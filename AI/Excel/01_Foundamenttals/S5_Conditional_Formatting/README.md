# Conditional Formatting 
هدف امروز: جدول EPC را طوری طراحی کنی که با نگاه به آن، تأخیر بحرانی، موعد نزدیک و ایراد داده را تشخیص بدهی؛ بدون رنگ‌کردن دستی.

تا امروز:

    داده را پاک‌سازی کردیم؛
    تاریخ‌ها را استاندارد کردیم؛
    ورودی‌ها را محدود کردیم.

امروز خطا و ریسک را قابل‌دیدن می‌کنیم.
```
اصل امروز: رنگ باید نتیجه‌ی یک قانون قابل‌توضیح باشد، نه جایگزین داده و شاخص.
```

 ## آماده‌سازی فایل

از فایل روز چهارم یک نسخه ذخیره کن:
```
W01_D05_EPC_Alerts.xlsx
```
برای مثال‌های امروز، چینش جدول در شیت Calendar را این‌طور در نظر می‌گیریم:
```
ستون 	عنوان 	نقش
A 	ProjectID 	کد پروژه
B 	PackageID 	کد بسته
C 	StartDate 	شروع
D 	ApprovedFinish 	موعد مصوب
E 	ActualDelivery 	تحویل واقعی
F 	Status 	وضعیت
G 	Quantity 	مقدار
H 	InputCheck 	کنترل روز چهارم
I 	SupplierID 	کد تأمین‌کننده
J 	DelayDays 	تأخیر تقویمی
K 	DueInDays 	روز باقی‌مانده تا موعد
```
ردیف اول عنوان است و داده‌ها از ردیف دوم شروع می‌شوند.

اگر ترتیب ستون‌های فایلت متفاوت است، ارجاع فرمول‌ها را متناسب تغییر بده.
یک تاریخ مبنا تعریف کن

در شیت جدید Settings:
```
سلول 	محتوا
A1 	ReportDate
B1 	=DATE(2026,4,30)
```
برای B1 نام زیر را تعریف کن:

```
ReportDate
```
امروز تاریخ گزارش را ثابت می‌گیریم تا جواب تمرین‌ها قابل‌مقایسه باشد.

برای داشبورد زنده می‌توانی بعداً مقدار آن را به این تبدیل کنی:
```
=TODAY()
```
نکته: TODAY() هنگام محاسبه‌ی مجدد فایل به‌روز می‌شود؛ ساعتِ دائماً در حال اجرا نیست.

## فرمول بولین چیست؟

فرمولی که خروجی آن TRUE یا FALSE است:

```
=J2>30
```
یعنی آیا تأخیر این ردیف بیشتر از ۳۰ روز است؟

Conditional Formatting همین منطق را استفاده می‌کند:
```
    TRUE ← قالب را اعمال کن.
    FALSE ← این قالب را اعمال نکن.
```
سه ابزار منطقی

```
=AND(J2>30,F2<>"Delivered")
```
یعنی هر دو شرط برقرار باشند.

```
=OR(F2="Pending",F2="In Progress")
```
یعنی حداقل یکی برقرار باشد.

```
=$E2=""
```
یعنی تاریخ تحویل خالی باشد.

در Conditional Formatting معمولاً نیازی نیست بنویسی:

```
=IF(J2>30,TRUE,FALSE)
```
همان مقایسه‌ی ساده کافی است:

```
=J2>30
```
نقش $ در رنگ‌کردن کل ردیف

فرض کن محدوده‌ی زیر را انتخاب کرده‌ای:

```
A2:K201
```
و می‌خواهی رنگ هر ردیف به تأخیر ستون J همان ردیف وابسته باشد.

فرمول درست:

```
=$J2>30
```
```
ارجاع 	رفتار
J2 	ستون و ردیف هر دو نسبی‌اند؛ برای کل ردیف مناسب نیست
$J2 	ستون J ثابت، ردیف متغیر؛ انتخاب درست این تمرین
J$2 	ردیف ۲ ثابت، ستون متغیر
$J$2 	همه‌ی سلول‌ها فقط به J2 وابسته‌اند
تصویر ذهنی
```
با فرمول:

```
=$J2>30
```
    - تمام سلول‌های ردیف ۲ به J2 نگاه می‌کنند.
    - تمام سلول‌های ردیف ۳ به J3 نگاه می‌کنند.
    - تمام سلول‌های ردیف ۴ به J4 نگاه می‌کنند.

قاعده‌ی کلیدی: فرمول را نسبت به سلول بالای چپ محدوده‌ی هدف بنویس و هنگام ساخت قانون، همان سلول را فعال نگه دار.
## اولین قانون: هایلایت کل ردیف

ابتدا برای آزمایش، در چند سلول ستون J مقدارهای زیر را بگذار:
```
0
15
30
31
45
```
سپس A2:K6 را با فعال‌بودن A2 انتخاب کن:

```
Home → Conditional Formatting → New Rule
→ Use a formula to determine which cells to format
```
فرمول:

```
=AND(ISNUMBER($J2),$J2>30)
```
قالب:

    پس‌زمینه قرمز روشن؛
    متن تیره و خوانا.

در Manage Rules بررسی کن:

```
Applies to: =$A$2:$K$6
```
فقط ردیف‌های 31 و 45 باید رنگ بگیرند.

تفاوت مهم:

```
>30
```
یعنی بیشتر از ۳۰، نه ۳۰ و بیشتر.

پس مقدار 30 نباید قرمز شود.

بعد از این آزمایش، اعداد دستی ستون J را پاک کن؛ در پروژه‌ی شب این ستون فرمولی خواهد شد.
## تأخیر بسته‌ی باز و تحویل‌شده یکسان محاسبه نمی‌شود
بسته‌ی تحویل‌شده

```
تأخیر = تاریخ تحویل واقعی − موعد مصوب
```
بسته‌ی هنوز تحویل‌نشده

```
تأخیر تا گزارش = تاریخ گزارش − موعد مصوب
```
در هر دو حالت، اگر نتیجه منفی باشد، تأخیر را صفر می‌گیریم.
مثال

موعد مصوب: ۱۰ مارس

تاریخ گزارش: ۳۰ آوریل

    اگر ۲۰ مارس تحویل شده باشد، تأخیر ۱۰ روز است.
    اگر هنوز تحویل نشده باشد، تأخیر تا گزارش ۵۱ روز است.

    استفاده از TODAY() برای تمام ردیف‌ها باعث می‌شود تأخیر بسته‌های قبلاً تحویل‌شده هم به‌اشتباه افزایش پیدا کند.

دامنه‌ی تمرین امروز: تاریخ‌های واقعی تحویل نباید بعد از ReportDate باشند. برای بازسازی وضعیت یک پروژه در گذشته، به منطق گزارش تاریخی یا داده‌ی Snapshot نیاز داریم.
۶. هشدار موعد نزدیک

برای بسته‌ی باز با موعد طی هفت روز آینده، شامل امروز:

```
=AND(ISNUMBER($D2),$E2="",$D2>=ReportDate,$D2<=ReportDate+7)
```
قالب پیشنهادی: زرد روشن.

معنای اجزا:
```
شرط 	معنا
ISNUMBER($D2) 	موعد، مقدار عددی تاریخ داشته باشد
$E2="" 	هنوز تحویل نشده باشد
$D2>=ReportDate 	موعد نگذشته باشد
$D2<=ReportDate+7 	حداکثر هفت روز تا موعد باقی باشد
```
چرا کنترل نوع داده مهم است؟

سلول خالی یا تاریخ متنی نباید صرفاً به‌خاطر نتیجه‌ی یک مقایسه، موعد معتبر فرض شود.

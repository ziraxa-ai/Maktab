## تاریخ و تقویم پروژه EPC

**هدف امروز**: بتوانی تاریخ متنی را از تاریخ واقعی تشخیص بدهی، موعدهای قراردادی را محاسبه کنی و تأخیر تحویل را با تقویم کاری درست بسنجی.

``` اصل امروز: تاریخ معتبر + تقویم کاری مشخص + تعریف روشن تأخیر = شاخص قابل‌اعتماد ```

فرمول‌ها بر مبنای تاریخ میلادی‌اند. اگر فایل‌های پروژه‌ات تاریخ شمسی دارند، آن‌ها را صرفاً با تغییر Format به تاریخ میلادی تبدیل نکن؛ تبدیل تقویم، مسئله‌ای جداست.
. اکسل تاریخ را چگونه ذخیره می‌کند؟

در سیستم تاریخ ۱۹۰۰ که در بیشتر فایل‌های امروزی رایج است:

  - عدد 1 نشان‌دهنده‌ی ۱ ژانویه‌ی ۱۹۰۰ است.
  - هر روز یک واحد به مقدار اضافه می‌کند.
  - ساعت، بخش اعشاری مقدار است؛ مثلاً 0.5 یعنی ساعت ۱۲ ظهر.

بنابراین:

```
Excel

=DATE(2026,4,3)+0.5
```

یعنی ۳ آوریل ۲۰۲۶، ساعت ۱۲ ظهر.

قالب سفارشی زیر را اعمال کن:

```
text

yyyy-mm-dd hh:mm
```
آزمایش

در A2 بنویس:

```
Excel

=DATE(2026,4,3)
```
سپس:

```
Excel

=ISNUMBER(A2)
```

باید TRUE شود. قالب A2 را بین General و Date تغییر بده: نمایش تغییر می‌کند، مقدار ذخیره‌شده نه.
دو تله‌ی تاریخی

۱. اکسل برای سازگاری قدیمی، در سیستم ۱۹۰۰ روز خیالی ۲۹ فوریه‌ی ۱۹۰۰ را هم حساب می‌کند. برای پروژه‌های امروزی معمولاً مسئله‌ساز نیست، اما سریال‌های بسیار قدیمی نیاز به احتیاط دارند.

۲. سیستم تاریخ ۱۹۰۴ هم وجود دارد؛ اختلاف دو سیستم ۱۴۶۲ روز است. اگر هنگام جابه‌جایی داده بین فایل‌ها تاریخ حدود چهار سال جابه‌جا شد، تنظیم سیستم تاریخ را بررسی کن؛ با کم‌وزیادکردن دستی روزها مسئله را پنهان نکن.

### 2. DATE: ساخت تاریخ بدون ابهام منطقه‌ای

ساختار:

```
Excel

=DATE(year,month,day)
```
مثال:
```
Excel

=DATE(2026,4,3)
```
این فرمول صریحاً تاریخ ۳ آوریل را می‌سازد، برخلاف ورودی مبهم:
```
Text

03/04/2026
```
که ممکن است بر اساس تنظیمات منطقه‌ای، ۴ مارس یا ۳ آوریل تفسیر شود.
تله‌ی مهم: DATE اعتبارسنج سخت‌گیر نیست
```
 Excel                                                                 
=DATE(2026,2,30)
```
خطا نمی‌دهد؛ تاریخ را به ۲ مارس ۲۰۲۶ منتقل می‌کند.

پس اگر روز و ماه را از متن استخراج کردی، ساخته‌شدن تاریخ به‌تنهایی صحت ورودی را ثابت نمی‌کند.

قاعده: سال را چهاررقمی وارد کن.
### ۳. EDATE: جابه‌جایی به‌اندازه‌ی ماه تقویمی


```
Excel

=EDATE(start_date,months)
```
مثال:
```
Excel

=EDATE(DATE(2026,1,15),3)
```
خروجی:
```
Text

2026-04-15
```
برای ماه قبل:

```
Excel

=EDATE(A2,-1)
```

کاربرد EPC

اگر قرارداد می‌گوید تحویل سه ماه پس از شروع است:

```
Excel

=EDATE([@StartDate],3)
```
نه:

```
Excel

=[@StartDate]+90
```
سه ماه تقویمی الزاماً ۹۰ روز نیست.

در پایان ماه:

```
Excel

=EDATE(DATE(2026,1,31),1)
```
خروجی 2026-02-28 است؛ چون فوریه روز ۳۱ ندارد.

### ۴. EOMONTH: آخرین روز ماه

```
Excel

=EOMONTH(start_date,months)
```
مثال‌ها:

```
Excel

=EOMONTH(DATE(2026,1,15),0)
```
خروجی: 2026-01-31

```
Excel

=EOMONTH(DATE(2026,1,15),1)
```
خروجی: 2026-02-28

اول ماه جاری:

```
Excel

=EOMONTH(A2,-1)+1
```
کاربرد مهندسی

    تعیین ماه گزارش هزینه؛
    گروه‌بندی تحویل‌ها در ماه مربوط؛
    ساخت تاریخ پایان دوره‌ی گزارش.

ستون ماه تحویل:

```
Excel

=EOMONTH([@ActualDelivery],0)
```
می‌توانی قالبش را yyyy-mm بگذاری. مقدار همچنان تاریخ عددی باقی می‌ماند، نه متن.

تفاوت مهم: EDATE روز متناظر ماه را می‌خواهد؛ EOMONTH همیشه آخر ماه را برمی‌گرداند.

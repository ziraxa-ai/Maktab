## تاریخ و تقویم پروژه EPC

**هدف امروز**: بتوانی تاریخ متنی را از تاریخ واقعی تشخیص بدهی، موعدهای قراردادی را محاسبه کنی و تأخیر تحویل را با تقویم کاری درست بسنجی.

``` اصل امروز: تاریخ معتبر + تقویم کاری مشخص + تعریف روشن تأخیر = شاخص قابل‌اعتماد ```

فرمول‌ها بر مبنای تاریخ میلادی‌اند. اگر فایل‌های پروژه‌ات تاریخ شمسی دارند، آن‌ها را صرفاً با تغییر Format به تاریخ میلادی تبدیل نکن؛ تبدیل تقویم، مسئله‌ای جداست.
. اکسل تاریخ را چگونه ذخیره می‌کند؟

در سیستم تاریخ ۱۹۰۰ که در بیشتر فایل‌های امروزی رایج است:

  - عدد 1 نشان‌دهنده‌ی ۱ ژانویه‌ی ۱۹۰۰ است.
  - هر روز یک واحد به مقدار اضافه می‌کند.
  - ساعت، بخش اعشاری مقدار است؛ مثلاً 0.5 یعنی ساعت ۱۲ ظهر.

بنابراین:

```
Excel

=DATE(2026,4,3)+0.5
```

یعنی ۳ آوریل ۲۰۲۶، ساعت ۱۲ ظهر.

قالب سفارشی زیر را اعمال کن:

                                                                    text
yyyy-mm-dd hh:mm

آزمایش

در A2 بنویس:

                                                                    excel
=DATE(2026,4,3)

سپس:

                                                                    excel
=ISNUMBER(A2)

باید TRUE شود. قالب A2 را بین General و Date تغییر بده: نمایش تغییر می‌کند، مقدار ذخیره‌شده نه.
دو تله‌ی تاریخی

۱. اکسل برای سازگاری قدیمی، در سیستم ۱۹۰۰ روز خیالی ۲۹ فوریه‌ی ۱۹۰۰ را هم حساب می‌کند. برای پروژه‌های امروزی معمولاً مسئله‌ساز نیست، اما سریال‌های بسیار قدیمی نیاز به احتیاط دارند.

۲. سیستم تاریخ ۱۹۰۴ هم وجود دارد؛ اختلاف دو سیستم ۱۴۶۲ روز است. اگر هنگام جابه‌جایی داده بین فایل‌ها تاریخ حدود چهار سال جابه‌جا شد، تنظیم سیستم تاریخ را بررسی کن؛ با کم‌وزیادکردن دستی روزها مسئله را پنهان نکن.

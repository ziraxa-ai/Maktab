## تاریخ و تقویم پروژه EPC

**هدف امروز**: بتوانی تاریخ متنی را از تاریخ واقعی تشخیص بدهی، موعدهای قراردادی را محاسبه کنی و تأخیر تحویل را با تقویم کاری درست بسنجی.

``` اصل امروز: تاریخ معتبر + تقویم کاری مشخص + تعریف روشن تأخیر = شاخص قابل‌اعتماد ```

فرمول‌ها بر مبنای تاریخ میلادی‌اند. اگر فایل‌های پروژه‌ات تاریخ شمسی دارند، آن‌ها را صرفاً با تغییر Format به تاریخ میلادی تبدیل نکن؛ تبدیل تقویم، مسئله‌ای جداست.

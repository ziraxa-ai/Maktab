
# Table and Data Type
**امروز** می خواهیم با Table آشنا بشویم و ببینیم با Range چه تفاوت هایی دارد .

### Range

- **مجموعه ای از سلول ها است.**
- آدرس دهی آن به شکل : 

``` 
excel

A1 : G13

```
### Table 
- **محدوده ای است که اکسل آن را به عنوان یک جدول ساختار یافته با نام، ستون و ردیف می داند.**



| ویژگی           | Range معمولی                                | Table                                        |
| --------------- | ------------------------------------------- | -------------------------------------------- |
| آدرس‌دهی        | مثل `D2:D13`                                | مثل `tblBOQ[Quantity]`                       |
| اضافه‌کردن ردیف | گسترش فرمول‌ها و منابع همیشه تضمین‌شده نیست | معمولاً جدول خودکار گسترش می‌یابد            |
| فرمول ستون      | نیازمند کپی یا تنظیم                        | در ستون محاسباتی معمولاً خودکار تکثیر می‌شود |
| فیلتر           | باید فعالش کنی                              | در سرستون‌ها آماده است                       |
| خوانایی فرمول   | وابسته به آدرس سلول‌ها                      | وابسته به نام ستون‌ها                        |
| کاربرد در پروژه | مناسب محاسبات پراکنده                       | مناسب داده‌ی ورودی گزارش و Power Query       |

**نکته:** Table فقط جدول رنگی نیست؛ رفتار داده را تغییر می‌دهد.

### ساخت Table

۱. داخل داده کلیک کن.
۲. `Ctrl + T` را بزن.
۳. محدوده را بررسی کن.
۴. اگر ردیف اول عنوان ستون‌هاست، گزینه‌ی **My table has headers** را فعال کن.
۵. از تب **Table Design**، نام جدول را تغییر بده.

### قواعد نام‌گذاری

- فاصله نداشته باشد.
- با عدد شروع نشود.
- شبیه آدرس سلول، مثلاً `A1`، نباشد.
- در فایل یکتا باشد.
- معنای مشخص داشته باشد.

نمونه:

```

`tblBOQ
 tblActualCost
 tblSuppliers`

```


پیشوند `tbl` **الزامی نیست**؛ قرارداد ما برای تشخیص سریع جدول‌هاست.
### قواعد ساختاری داده

از امروز این پنج قانون را رعایت کن:

1. هر ردیف = یک رکورد.
2. هر ستون = یک ویژگی.
3. سرستون‌ها یکتا و مشخص.
4. بدون سلول Merge‌شده داخل داده.
5. بدون ردیف جمع دستی وسط رکوردها.

## ارجاع ساختار یافته چیست؟

در **Range** برای محاسبه هر ردیف باید بنویسیم:

```
Excel
= D2 * E2
```

اما در **Table** :

```
Excel
=[@Quantity]*[@UnitRate]
```

**نکته:**
**@** به همان ردیفی که داده ها داخلش هستد اشاره می کند، 

**سه شکل پر تکرار:**

| ارجاع              | معنی                                             |
| ------------------ | ------------------------------------------------ |
| `tblBOQ[Quantity]` | داده‌های کل ستون Quantity، بدون عنوان و ردیف جمع |
| `[@Quantity]`      | مقدار Quantity در ردیف جاری                      |
| `tblBOQ[#All]`     | کل جدول، شامل عنوان‌ها و ردیف جمع در صورت وجود   |

**هشدار مهندسی:** اگر Quantity شامل متر، کیلوگرم و عدد باشد، جمع کل آن معنی ندارد! درست‌بودن فرمول لزوماً به معنی درست‌بودن شاخص نیست.

## نوع داده با قالب نمایش فرق دارد

**قالب سلول، ظاهر مقدار را کنترل می کند؛ لزوما نوع مقدار ذخیره شده را تغییر نمیدهد**

در سلول‌های معمولی اکسل با این موارد مواجه می‌شویم:

| نوع مقدار | مثال             | کاربرد             |
| --------- | ---------------- | ------------------ |
| عدد       | `1250` یا `0.25` | هزینه، مقدار، درصد |
| متن       | `PRJ-01`         | شناسه، توضیح، نام  |
| منطقی     | `TRUE` / `FALSE` | نتیجه‌ی شرط        |
| خطا       | `#VALUE!`        | محاسبه‌ی نامعتبر   |
| خالی      | سلول بدون مقدار  | داده‌ی ثبت‌نشده    |

**تاریخ و ساعت معتبر اکسل، مقدار عددی دارند**؛ قالب تاریخ یا ساعت تعیین می‌کند چگونه نمایش داده شوند.

همچنین **Table** معمولی برای یک ستون «نوع داده‌ی سخت‌گیرانه» تعیین نمی‌کند. ممکن است در یک ستون هم عدد باشد، هم متن و هم خطا.

### مثال: عدد واقعی و عدد متنی

این دو مقدار ممکن است یکسان دیده شوند:


`1250 '1250`

در دومی، آپاستروف ابتدایی به اکسل می‌گوید مقدار را متن نگه دارد. خود آپاستروف معمولاً در نمایش سلول دیده نمی‌شود.

برای تشخیص:


`=ISNUMBER(A2)`


`=ISTEXT(A2)`



|مقدار ورودی|ISNUMBER|ISTEXT|
|---|---|---|
|`1250`|TRUE|FALSE|
|`'1250`|FALSE|TRUE|

راست‌چین یا چپ‌چین بودن فقط یک سرنخ است؛ با تغییر Alignment دیگر قابل‌اعتماد نیست.

## General

یعنی قالب عمومی، نه تضمین نوع داده درست.
### تله‌ی اول: حذف صفر ابتدایی

اگر در سلول General بنویسی:

```
`00125`
```
اکسل معمولاً آن را به عدد زیر تبدیل می‌کند:

```
`125`
```
اگر این مقدار **کد کالا** باشد، صفرها بخشی از هویت آن‌اند.
راه درست:

- ستون شناسه را **پیش از ورود داده** Text کنیم.
- برای ورود دستی محدود، از `'00125` استفاده کنیم.

قالب سفارشی `00000` فقط ظاهر عدد را پنج‌رقمی می‌کند؛ آن را به شناسه‌ی متنی تبدیل نمی‌کند.


### تله‌ی دوم: تغییر قالب، عدد متنی را اصلاح نمی‌کند

اگر مقدار `'1250` را وارد کنیم و سپس قالبش را Number بگذاریم، معمولاً همچنان **متن** می‌ماند.

پس این گزاره غلط است:

> «ستون را Number کردم، پس همه‌ی مقادیرش عدد شدند.»

بعد از اصلاح باید دوباره با ***`ISNUMBER`*** آزمایش می کنیم.

### تله‌ی سوم: شناسه‌های بلند

اکسل برای اعداد دقتی در حد **۱۵ رقم معنادار** دارد. شناسه‌های عددی بیش از ۱۵ رقم باید از ابتدا متن باشند.

اگر هنگام ورود، رقم‌های شناسه تغییر کرده باشند، Text‌کردن بعدی آن‌ها را بازیابی نمی‌کند؛ باید از منبع اصلی دوباره وارد شوند.

### تله‌ی چهارم: تاریخ مبهم

ورودی زیر با توجه به تنظیمات منطقه‌ای ممکن است متفاوت تفسیر شود یا متن باقی بماند:

```
`03/04/2026`
```

برای آزمایش بدون ابهام می نویسیم:
```
`=DATE(2026,4,3)`
```

قالب را به Date و سپس General تغییر میدهیم:

- در Date، تاریخ می‌بینیم.
- در General، شماره‌ی سریال تاریخ می‌بینیم.
- `ISNUMBER` در هر دو حالت `TRUE` است.

**نکته‌ی پروژه‌ی فارسی:** تاریخ شمسی تایپ‌شده را صرفاً به دلیل ظاهرش تاریخ معتبر اکسل فرض نکن. تبدیل و مدیریت آن را جداگانه بررسی خواهیم کرد.

## خب حالا به پاکسازی داده و استخراج داده از متن رسیدیم

امروز می خواهیم داده های :

               شركت   فولاد شرق | prj-02 | sup-007

را به سه خروجی :

                   CompanyName: شرکت فولاد شرق
                   ProjectID: PRJ-02
                   SupplierID: SUP-007


تبدیل کنیم.

اصل حرفه‌ای امروز:

    اول متن را استاندارد کن ، بعد اجزای آن را استخراج کن؛ حتما داده های خام را هم حفظ کن

ابتدا با یک مفهوم به نام **تابع(Function)** آشنا می شویم،
تابع در اکسل یک فرمول از پیش تعیین شده می باشد که محاسبات یا عملیات مشخصی را روی مجموعه‌ای از داده‌ها (ورودی‌ها و آرگومان‌ها) انجام می دهد.

توابع متنی اکسل ابزارهای قدرتمندی برای پاکسازی سبک داده‌ها و استخراج اطلاعات از متن‌های نامرتب هستند.
- **پاکسازی متن** : حذف فاصله اضافی با تابع TRIM، تبدیل حروف به بزرگ یا کوچک به کمک توابع UPPER, LOWER.
- **استخراج داده** : جدا کردن بخشی از متن (مثل نام یا کد) از چپ، راست یا وسط با RIGHT, LEFT, MID .
- **جستجو و جایگزینی** : پیدا کردن جایگاه یک کاراکتر با FIND یا جایگزینی متن به کمک SUBTITUTE.
  مثال برای جدا کردن ۳ حرف اول یک کد از سلول A1:

               =LEFT(A1, 3)

## آشنایی با چندتابع،

#### تابع اول (TRIM) برای حذف فاصله اضافی،
این تابع:
- فاصله‌های معمولی ابتدا و انتهای متن را حذف میکند.
- چند فاصله‌ی معمولی بین کلمات را به یک فاصله تبدیل میکند.
مثالش رو ببینیم:

             قبل: "   شرکت    فولاد   شرق  "
             بعد: "شرکت فولاد شرق"

**محدودیت مهم** : TRIM همه فاصله‌ها را نمیشناسد، مثل فاصله هایی که از وب ها کپی می شود، به عنوان راه حل برای این موضوع مثال ساختار را ببینید.

**ساختار**:

         =TRIM(SUBSTITUTE(A2,CHAR(160)," "))

ما اینجا ابتدا فاصلی نشکن 160 را به فاصله معمولی تبدیل کردیم، سپس فاصله ها را مرتب میکنیم.

#### تابع دوم (CLEAN)برای حذف بعضی نویسه‌های کنترلی

           =CLEAN(A2)

ین تابع فقط کاراکترهای فنیِ پایه‌ای (مثل اینتر و تب) را پاک می‌کند، نه تمام کاراکترهای مخفی و نامرئی متن را.

**تله مهم:** چسبیدن کلمات
فرض کن یه متن داریم،

           ="شرکت"&CHAR(10)&"فولاد"

اگر مستقیما cleanرا اجرا کنیم در خروجی داریم:

           شرکتفولاد

 برای حفظ مرز کلمات، ابتدا شکست خط را به فاصله تبدیل کن:

           =TRIM(CLEAN(SUBSTITUTE(A2,CHAR(10)," ")))

بزار به زبون آدمیزاد توضیح بدم:
- در بخش اول (SUBTITUTE) میگیم، ای اکسل من! هرجا توی سلول A2 به کلید اینتر(کد10)رسیدی، حذفش نکن، بلکه بجاش یک فاصله(Space) بگذار تا کلمات به هم نچسبند.
- بعد تابع Clean و TRIM دوروبر متن را تمیز می کنند، تا فاصله‌های اضافی و کاراکترهای خراب باقی مانده هم پاک شوند.

  

#### فرمول دوم: برای تب، اینتر و بازگشت خط (کامل‌تر)

                                                                    
            =TRIM(CLEAN(SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(A2,CHAR(9)," "),CHAR(10)," "),CHAR(13),"")))

    توضیح به زبان آدمیزاد:

    این دقیقاً همان فرمول بالاست، با این تفاوت که به جای یک کلید، حواسش به سه تا کلید نامرئیِ پرکاربرد هست:
        کلید Tab (کد ۹) ←← جایش فاصله می‌گذارد.
        کلید Enter یا شکست خط (کد ۱۰) ←← جایش فاصله می‌گذارد.
        کلید Enter قدیمی یا بازگشت خط (کد ۱۳) ←← جایش فاصله می‌گذارد.

    در نهایت هم CLEAN و TRIM متن را کاملاً صیقل می‌دهند و تمیز تحویلتان می‌دهند.

خلاصه در یک جمله: این فرمول‌ها می‌گویند: «قبل از اینکه کاراکترهای **نامرئیِ متن را پاک کنی**، اول بهشان یک فاصله بده تا کلماتت له و چسبیده نشوند، بعد تمیزشان کن!»



. SUBSTITUTE: جایگزینی هدفمند

ساختار:

                                                                    excel
=SUBSTITUTE(text,old_text,new_text,[instance_num])

مثال:

                                                                    excel
=SUBSTITUTE(A2,";","|")

تمام ;ها را به | تبدیل می‌کند.

اگر فقط دومین مورد را بخواهی:

                                                                    excel
=SUBSTITUTE(A2,";","|",2)

کاربرد بسیار مهم در داده‌ی فارسی

ظاهر این حروف مشابه است، اما یکسان نیستند:
حرف عربی 	حرف فارسی استاندارد ما
ي 	ی
ك 	ک

فرمول:

                                                                    excel
=SUBSTITUTE(SUBSTITUTE(A2,"ي","ی"),"ك","ک")

این تفاوت می‌تواند باعث شود دو نام ظاهراً یکسان در جستجو یا گروه‌بندی، متفاوت محسوب شوند.

احتیاط: نیم‌فاصله‌ی فارسی را بی‌دلیل حذف نکن. برای عبارتی مانند «تأمین‌کننده» بخشی از نگارش درست است؛ حذف یا تبدیل آن باید تابع یک قاعده‌ی مشخص باشد.
۵. PROPER: مرتب‌کردن حروف نام انگلیسی

                                                                    excel
=PROPER("pars industrial supply")

خروجی:

                                                                    text
Pars Industrial Supply

اما:

                                                                    excel
=PROPER("EPC ABB")

می‌شود:

                                                                    text
Epc Abb

بنابراین:

    برای بعضی نام‌های انگلیسی مفید است.
    برای مخفف‌ها و نام‌های تجاری همیشه مناسب نیست.
    روی فارسی، که حروف بزرگ و کوچک ندارد، این کاربرد را ندارد.
    برای شناسه‌ها از آن استفاده نکن.

برای یکدست‌کردن کدها از تابع کمکی زیر استفاده می‌کنیم:

                                                                    excel
=UPPER("prj-02")

خروجی:

                                                                    text
PRJ-02

۶. TEXTBEFORE و TEXTAFTER

فرض کن A2 برابر باشد با:

                                                                    text
شرکت فولاد شرق|PRJ-02|SUP-007

متن قبل از اولین جداکننده

                                                                    excel
=TEXTBEFORE(A2,"|")

خروجی:

                                                                    text
شرکت فولاد شرق

متن بعد از اولین جداکننده

                                                                    excel
=TEXTAFTER(A2,"|")

خروجی:

                                                                    text
PRJ-02|SUP-007

استخراج قسمت وسط

                                                                    excel
=TEXTBEFORE(TEXTAFTER(A2,"|"),"|")

خروجی:

                                                                    text
PRJ-02

متن بعد از آخرین جداکننده

                                                                    excel
=TEXTAFTER(A2,"|",-1)

خروجی:

                                                                    text
SUP-007

عدد -1 یعنی جستجو از انتهای متن.

محدودیت: این روش به ثابت‌بودن ترتیب اجزا وابسته است. اگر جای نام شرکت و کد پروژه تغییر کند، دیگر کافی نیست.
۷. TEXTSPLIT: شکستن متن به چند بخش

                                                                    excel
=TEXTSPLIT(A2,"|")

سه بخش را در سه سلول کنار هم قرار می‌دهد.

برای حذف فاصله‌های اطراف هر بخش:

                                                                    excel
=TRIM(TEXTSPLIT(A2,"|"))

نکته‌ی مهم درباره‌ی Table

خروجی چندسلولی TEXTSPLIT باید فضای خالی برای گسترش داشته باشد. آن را خارج از Table آزمایش کن؛ فرمول‌های آرایه‌ای گسترش‌یابنده داخل Table پشتیبانی نمی‌شوند.

اگر مسیر خروجی مسدود باشد، ممکن است #SPILL! ببینی.

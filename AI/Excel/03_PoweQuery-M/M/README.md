### در Excel

- مسیر معمول:

Data → Get Data → From Other Source → Blank Query

- سپس در پنجره Power Query Editor قرار میگیرید و مجددا :

Home → Advanced Editor

### در Power BI Desktop 

- ابتدا وارد Transform data می شویم ، سپس در Power Query Editor :
 Home → New Source → Blank Query 

بعد :
Home → Advanced Editor

ممکن است نام یا جای دقیق بعضی گزینه‌ها در نسخه‌های مختلف کمی متفاوت باشد.

# بخش اول: درک مدل ذهنی `let … in`

ساده بگیم : 

`let`
یک بلوکی را برای  تعریف نام‌ها و محاسبات تشکیل می دهد .
##### که در نهایت از ،
`in`
برای مشخص‌کردن نتیجه کل عبارت و تعین آن برای یک متغیر می باشد .

### یک مثال با چند گام 
let
    Price = 100,
    Quantity = 3,
    Total = Price * Quantity
in
    Total



خروجی آن :

300

### ## نقش کاما ( , ) در `let`

تعریف‌های داخل `let` با ویرگول انگلیسی `,` از یکدیگر جدا می‌شوند.

## دو نکته مهم :

let
    A = 10
    B = 20
in
    A + B

اینجا چون بین تعریف `A` و `B` جداکننده ( , ) وجود ندارد؛ این کد معتبر نیست.

let
    A = 10,
    B = 20,
in
    A + B

 و در اینجا ویرگول بعد از `B = 20` اضافه است.
